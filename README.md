# Weekly-Report-Generator
Weekly team report management system with role-based access, review workflow, and manager dashboard. Built with React, NestJS, and MySQL.

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, React Router, React Hook Form, Zod, Recharts, Axios
- **Backend:** NestJS 10, TypeScript, TypeORM, MySQL/MariaDB, Passport JWT, bcrypt, class-validator
- **Database:** MySQL 8+ or MariaDB 10.4+
